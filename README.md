# RemoteDesk – שליטה מרחוק על מחשב (כמו AnyDesk)

## איך זה עובד
```
 מחשב א' (שולט)  ──►  שרת מתווך (Relay)  ◄──  מחשב ב' (נשלט)
```
* כל מחשב מקבל **מספר מזהה קבוע בן 9 ספרות**, לא כתובת IP.
* שני המחשבים מתחברים **החוצה** לשרת המתווך, ולכן לא צריך IP קבוע, פתיחת פורטים או הגדרות בנתב.
* אותה תוכנה מותקנת בשני המחשבים. כל מחשב יכול גם לשלוט וגם להישלט.
* הממשק כולו בעברית.

## גישה מלאה כמנהל מערכת
כשמתקינים את התוכנה **כשירות מערכת** (כפתור "התקן כשירות מערכת"), היא רצה בהרשאות **SYSTEM**, ההרשאה הגבוהה ביותר ב-Windows. במצב הזה:

| | בלי שירות | עם שירות מערכת |
|---|---|---|
| שליטה בשולחן העבודה | ✅ | ✅ |
| חלונות UAC ("הפעל כמנהל") | ❌ | ✅ |
| מסך הכניסה והקלדת סיסמת Windows | ❌ | ✅ |
| מסך הנעילה (Win+L) | ❌ | ✅ |
| Ctrl+Alt+Del אמיתי | ❌ | ✅ |
| עובד אחרי הפעלה מחדש, לפני שמישהו נכנס | ❌ | ✅ |
| עובד כשחלון התוכנה סגור | ❌ | ✅ |
| מתאושש לבד אחרי קריסה | ❌ | ✅ |

חלון התוכנה עצמו תמיד נפתח כמנהל מערכת ומבקש אישור UAC.

## אבטחה
* **הסיסמה לא נשמרת בכלל.** נשמר רק מפתח שנגזר ממנה (PBKDF2). האימות נעשה בשני הכיוונים, כך שגם שרת מזויף לא יכול להתחזות למחשב שלך.
* **הצפנה מקצה לקצה (AES-256-GCM):** גם מי שמפעיל את השרת המתווך לא רואה את המסך, את ההקלדות ואת הקבצים.
* אחרי 5 סיסמאות שגויות המחשב ננעל ל-5 דקות.
* אי אפשר "לגנוב" מספר מזהה של מחשב אחר.
* תיקיית ההגדרות (`C:\ProgramData\RemoteDesk`) נגישה רק למנהלי מערכת.
* בזמן חיבור מופיע בראש המסך של המחשב הנשלט **פס אדום "המחשב נשלט מרחוק"** עם כפתור **נתק**.

## שלב 1: הקמת השרת המתווך (פעם אחת)
**א. Render.com (חינם)**
1. מעלים את התיקייה `remotedesk` ל-GitHub.
2. ב-Render: New → Blueprint, ובוחרים את ה-repo. הקובץ `render.yaml` יגדיר הכול.
3. מתקבלת כתובת כמו `https://remotedesk-relay.onrender.com`. **בתוכנה כותבים אותה כך:**
   `wss://remotedesk-relay.onrender.com`

**ב. שרת VPS משלך (יציב יותר, כ-5$ לחודש)**
```bash
cd server
```
```bash
docker build -t remotedesk-relay .
```
```bash
docker run -d --restart always -p 8765:8765 -v remotedesk:/data remotedesk-relay
```
הכתובת תהיה `ws://<כתובת-השרת>:8765`.

## שלב 2: קבלת תוכנת ההתקנה `RemoteDesk-Setup.exe`
התוכנה למחשב היא תוכנת Windows רגילה עם אשף התקנה בעברית. בונים אותה פעם אחת, באחת משתי הדרכים:

**דרך א': אוטומטית ב-GitHub, בלי להתקין כלום (מומלץ)**
1. פותחים חשבון ב-github.com ויוצרים repository חדש (אפשר פרטי).
2. מעלים אליו את כל התוכן של התיקייה `remotedesk`, כולל התיקייה `.github`.
3. נכנסים ללשונית **Actions**. הבנייה רצה לבד על מחשב Windows של GitHub ולוקחת כ-5 דקות.
4. בסיום, בתוך הריצה, מורידים את **RemoteDesk-Windows**. בתוכו נמצא `RemoteDesk-Setup.exe`.

**דרך ב': במחשב Windows שלך**
1. מתקינים Python 3.12 (python.org, עם סימון Add to PATH) ו-Inno Setup 6 (jrsoftware.org).
2. לוחצים פעמיים על `client\build_windows.bat`.
3. נוצר הקובץ `client\dist\RemoteDesk-Setup.exe`.

## שלב 3: התקנה בכל מחשב
1. מעתיקים את `RemoteDesk-Setup.exe` לכל מחשב, מריצים אותו ומאשרים את חלון ה-UAC.
2. באשף מסמנים **"התקן כשירות מערכת"** (מסומן מראש). כך מתקבלת גישה מלאה כמנהל מערכת.
3. בסוף ההתקנה התוכנה נפתחת. ב**כתובת שרת** כותבים את כתובת השרת המתווך ולוחצים **החל**.
4. בוחרים **סיסמה** ולוחצים **שמור סיסמה**.
5. רושמים את **המספר שלך**.

התוכנה מופיעה בתפריט התחל ובשולחן העבודה, ומסירים אותה כמו כל תוכנה, דרך "הגדרות ← אפליקציות". ההסרה מוחקת גם את השירות.

## שימוש
במחשב השולט מקלידים את המספר של המחשב השני ב**מספר המחשב המרוחק**, לוחצים **התחבר** ומקלידים את הסיסמה שלו.

בחלון השליטה יש:
* עכבר מלא (כולל לחצן ימני וגלגלת) ומקלדת מלאה, כולל עברית.
* **Ctrl+Alt+Del** אמיתי.
* **שלח קובץ:** הקובץ נשמר במחשב המרוחק בתיקייה `RemoteDesk` שעל שולחן העבודה.
* **הקלד טקסט מהלוח:** מקליד במחשב המרוחק את הטקסט שהעתקת.
* **איכות:** מהיר / מאוזן / גבוה / מקסימלי.
* **מסך:** בחירת מסך כשיש כמה מסכים.

## 📱 שליטה מהטלפון הנייד (אנדרואיד ואייפון)
לא צריך להתקין שום דבר מחנות האפליקציות: השרת המתווך מגיש אפליקציית ווב לטלפון.

1. פותחים בטלפון את כתובת השרת בדפדפן, למשל `https://remotedesk-relay.onrender.com`.
   **חובה https.** ב-Render זה מגיע אוטומטית. בשרת VPS צריך דומיין ותעודה, ראו בהמשך.
2. מקלידים את מספר המחשב ואת הסיסמה ולוחצים **התחבר**.
3. כדאי להוסיף את האפליקציה למסך הבית ("הוסף למסך הבית" בתפריט של Chrome או של Safari). כך היא נפתחת כמו אפליקציה רגילה, במסך מלא.

### מחוות מגע
| | 👆 מגע ישיר (ברירת מחדל) | 🖱️ משטח מגע |
|---|---|---|
| נגיעה | לחיצה במקום שנגעת | לחיצה במקום הסמן |
| גרירה באצבע אחת | גרירה עם העכבר | הזזת הסמן |
| לחיצה ארוכה | לחצן ימני | גרירה (מחזיקים וגוררים) |
| שתי אצבעות | זום והזזת התצוגה | גלילה |
| נגיעה בשתי אצבעות | לחצן ימני | לחצן ימני |

### כפתורים
* **⌨️:** פותח את מקלדת הטלפון, כולל עברית.
* **Ctrl/Esc:** שורת מקשים מיוחדים: Ctrl, Alt, Shift, Win, Esc, Tab, חיצים, F1 עד F12, גלילה. מקשי Ctrl, Alt, Shift ו-Win נשארים לחוצים עד המקש הבא (למשל Ctrl ואז c = העתקה).
* **Ctrl+Alt+Del**, **📁 שלח קובץ** מהטלפון למחשב, **איכות**, **מסך** ו-**⛶ מסך מלא**.
* המסך של הטלפון לא נכבה במהלך החיבור.

הטלפון יכול לשלוט במחשבים, אבל אי אפשר לשלוט בטלפון עצמו.

### HTTPS בשרת VPS
הדפדפן בטלפון מאפשר הצפנה רק בכתובת https. הדרך הפשוטה ביותר היא Caddy, שמנפיק תעודה בחינם ומחדש אותה אוטומטית:
```bash
docker run -d --restart always --network host caddy caddy reverse-proxy --from remote.your-domain.com --to localhost:8765
```
ואז במחשבים מגדירים את הכתובת `wss://remote.your-domain.com`, ובטלפון פותחים `https://remote.your-domain.com`.

## ⭐ מחשבים שמורים (כניסה בלי סיסמה)
* **בפעם הראשונה** מתחברים עם הסיסמה ומסמנים "שמור את המחשב". אפשר גם ללחוץ **"בקש אישור מהצד השני"**: בצד השני קופץ חלון עם קוד אימות בן 6 ספרות, ומי שיושב שם לוחץ **אשר** ומסמן "אפשר תמיד".
* **מהפעם השנייה** לוחצים פעמיים על המחשב בלשונית **"מחשבים שמורים"** (או נוגעים בו באפליקציית הטלפון) ונכנסים מיד, בלי סיסמה.
* **בצד הנשלט**, בלשונית **"מורשים להיכנס אליי"**, רואים מי מורשה ואפשר לבטל הרשאה בכל רגע.
* קוד האימות מגן מפני התחזות: אם הקוד אצלך שונה מהקוד בצד השני, לא מאשרים.

## 📱 אפליקציית האנדרואיד
האפליקציה עושה את שני הדברים:
* **שליטה במחשבים מתוך האפליקציה** (המסך הראשי): מחשבים שמורים, הקלדת מספר, מסך מלא בזמן חיבור. אין צורך ב-Chrome.
* **שליטה בטלפון עצמו** (הכרטיס "📱 הטלפון הזה" במסך הראשי), לפי ההוראות בהמשך.

## 📱 שליטה בטלפון אנדרואיד (הטלפון כמחשב נשלט)
1. מורידים לטלפון את **`RemoteDesk-Android.apk`** מעמוד ההורדות ומתקינים. אם הטלפון שואל, מאשרים "התקנה ממקורות לא ידועים".
2. פותחים את האפליקציה ולוחצים **"הפעל שיתוף מסך"**, ואז **"התחל"**.
3. לוחצים **"פתח הגדרות נגישות"** ← **RemoteDesk** ← **הפעל**. זה מאפשר לצד השני לגעת ולהקליד, ולא רק לראות.
4. רושמים את **המספר של הטלפון**. מתחברים אליו מהמחשב או מטלפון אחר בדיוק כמו למחשב.

**איך העכבר עובד על הטלפון:**

| פעולה במחשב | מה קורה בטלפון |
|---|---|
| לחיצה | נגיעה |
| לחיצה ארוכה | לחיצה ארוכה |
| גרירה | החלקה |
| לחצן ימני / Esc | חזור |
| גלגלת | גלילה |
| מקש Windows | מסך הבית |
| הקלדה | טקסט בשדה הפעיל (כולל עברית) |

**מגבלות של אנדרואיד:**
* אחרי כל הפעלה מחדש של הטלפון צריך לפתוח את האפליקציה וללחוץ "הפעל שיתוף מסך" פעם אחת, כי אנדרואיד דורש אישור של אדם. הטלפון מזכיר את זה בהתראה.
* כדי שאפליקציית RemoteDesk לא תיסגר ברקע, לוחצים באפליקציה על "אפשר פעולה ברקע".
* בחלק מהמכשירים (Samsung, Xiaomi) צריך גם לכבות "אופטימיזציית סוללה" ל-RemoteDesk בהגדרות.

**אייפון:** אפל לא מאפשרת לשום אפליקציה לשלוט באייפון מרחוק, גם לא ל-AnyDesk ול-TeamViewer. מאייפון אפשר רק **לשלוט** במחשבים, דרך האתר.

## 🔄 עדכונים אוטומטיים
מגרסה 1.0.7 והלאה אין צורך להתקין מחדש:
* **עם שירות מערכת:** השירות בודק פעם ב-6 שעות (ושתי דקות אחרי כל הפעלה) אם יש גרסה חדשה. אם יש, הוא מוריד אותה, מוודא את חתימת SHA-256 שלה, מחליף את הקובץ ומפעיל את עצמו מחדש. הוא אף פעם לא מתעדכן באמצע חיבור פעיל.
* **בלי שירות:** בחלון התוכנה מופיע הכפתור "עדכן עכשיו לגרסה X".
* מספר הגרסה מופיע בתחתית חלון התוכנה.

כדי לפרסם גרסה חדשה, מעלים שינוי לענף `main` ב-GitHub. הבנייה, הבדיקה והפרסום קורים אוטומטית, וכל המחשבים מתעדכנים לבד.

**חשוב:** כדי שהעדכונים יעבדו, ה-repository צריך להיות ציבורי (Public).

## הסרה
"הגדרות ← אפליקציות ← RemoteDesk ← הסר התקנה".

## פתרון בעיות
* **"המחשב המרוחק כבוי או שהמספר שגוי":** בודקים שבמחשב המרוחק כתוב "מוכן - ממתין לחיבורים" ושבשני המחשבים מוגדרת אותה כתובת שרת.
* **אנטי-וירוס חוסם:** תוכנות שליטה מרחוק שנבנו בעצמך מסומנות לפעמים כחשודות. צריך להוסיף חריגה לתיקייה `C:\Program Files\RemoteDesk`.
* **יומן השירות:** `C:\ProgramData\RemoteDesk\service.log`.

## מבנה הקבצים

| `client/build_windows.bat` | בניית התוכנה ותוכנת ההתקנה ב-Windows |
| `client/installer/RemoteDesk.iss` | אשף ההתקנה בעברית (Inno Setup) |
| `.github/workflows/build-windows.yml` | בנייה אוטומטית ב-GitHub |
